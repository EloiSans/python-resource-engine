# resource-engine-s3

`S3BlobStore`: the `BlobStore` port over the S3 API, for Resource Engine documents.
Works with AWS S3 and S3-compatible stores (Garage, MinIO, Ceph RGW, Cloudflare R2).
Tested against Garage (see `compose.emulators.yaml`).

See [documents](../../docs/documents.md) and the [adapter catalogue](../../docs/adapters.md).
Part of [Resource Engine](../../README.md).
