# Reference module: invoices

A complete, tested module: `domain/` (entity, state machine, events),
`application/` (resource, schemas, hooks, actions), `infrastructure/`
(SQLAlchemy imperative mapping), `bootstrap.py` (composition root),
`authz.py` (example policies) and `tests/`. It is the framework's own example
and runs in its test suite, so it matches the installed version.
